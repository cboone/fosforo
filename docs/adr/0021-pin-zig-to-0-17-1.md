# 0021. Pin Zig to 0.17.1

**Status:** Accepted

Supersedes [ADR 0002](./0002-zig-pinned-to-0-16-0.md).

## Context

Fósforo builds with an exact Zig version. Homebrew supplies 0.17.1, a patch release that addresses regressions from 0.17.0. Upgrading gives local builds and CI a common compiler. [Zig 0.17.1 release announcement](https://ziglang.org/news/0.17.1-released/)

## Decision

Pin `minimum_zig_version` to 0.17.1 in `build.zig.zon`. The pinned CI actions already read the manifest, so they select the new release from the same field. Schedule future compiler upgrades separately from feature work.

Pin CLAP 1.2.10 by its commit and existing package hash. Pin zig-objc to the upstream Zig 0.17 port at `bee663fdfaa0c554235dc36b1dce88d136a190ec` and its package hash. The existing clap-wrapper commit builds both wrapper bundles with the new Zig archive.

## Consequences

- Zig's optimization tags are now `.debug`, `.safe` and `.fast`. The compile-time test-mode check uses those tags. Struct reflection uses separate field names and attributes, and repeat-filled test arrays use `@splat`.
- Resolve the worktree path from the build root and the bundle path from Zig's install prefix. Disable configuration caching for the Git provenance query so each build records the current branch, commit and dirty state.
- The Objective-C bridge uses the upstream port. Its own test suite still fails to compile an empty exhaustive `enum(c_uint)` under 0.17.1. Fósforo builds against the unmodified dependency and exercises it through the GPU and AppKit smoke checks.
- CLAP still uses preprocessed headers with `translate-c`. Direct translation also exited successfully, but the existing path keeps the generated bindings and ABI checks in use. The SIMD code and the single-threaded `std.Io` backend build with their existing assertions.

## Verification

Homebrew Zig 0.17.1 built the direct CLAP bundle and the ReleaseFast archive used by CMake. `zig build audio-unit` built the Audio Unit and wrapper CLAP. The compiler passed 325 tests in each of `test`, `test-safe` and `test-release`. The GPU, trace, AppKit and 400-cycle leak checks passed locally. The leak report counted 18,816 bytes and found no project-owned classes. The Linux sanitizer harnesses cross-compiled on macOS. Their runtime checks and the hosted builds remain to be verified in CI. The standalone Metal syntax check requires an Xcode component that was unavailable on the test machine.
